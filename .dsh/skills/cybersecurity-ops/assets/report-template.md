## 写作检查

- [ ] 执行摘要不依赖技术附录也能读懂。
- [ ] 每个 finding 有状态/severity/priority/证据/修复/复测。
- [ ] `confirmed` 有直接证据或受控复现；`suspected` 没被写成确定。
- [ ] 时间统一 UTC；证据可定位。
- [ ] 已脱敏；没有真实凭据/客户数据。
- [ ] 限制和未测范围写清。
- [ ] 对外版本已获授权批准。
